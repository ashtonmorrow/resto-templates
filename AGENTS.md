# Folio

Leé `CLAUDE.md` antes de modificar el proyecto.

Folio es la guía principal. Folio Resto es el primer ejemplo abierto y vive
bajo la sección de demostraciones. Conservá esa diferencia en navegación,
breadcrumbs, títulos y llamadas a la acción.

Para escribir o editar guías en `src/data/guides.ts`, leé también
`voice/VOICE.md`. Ejecutá `npm run lint:voice` después de editar prosa. Los
hallazgos duros deben corregirse. Los avisos requieren una lectura humana, no
una sustitución automática.

Ejecutá `npm run verify` antes de dar por terminado un cambio que afecte el
sitio publicado.
